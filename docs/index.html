智慧分類器

用本地大型語言模型讀取客服信件，輸出固定 JSON 格式的類別、優先級、摘要與建議回覆，協助整理大量客服需求。

結構化輸出 JSON Schema5 種信件類別本地執行自動部署 Pages

01｜做了什麼

Python 透過 Ollama 的 /api/chat 呼叫 llama3.2，用 JSON Schema 限制回應欄位與有效分類。無需雲端 API Key。

02｜技術特色

AI 功能使用結構化輸出，程式另驗證欄位與類別；GitHub Actions 推送 main 後會執行自動測試並發佈本站。

04｜本機實測結果（真實模型輸出）


2026/10/31 在 Windows 命令提示字元使用 uv run python main.py 呼叫本地 Ollama。以下是從實際執行畫面轉錄的輸入與 JSON 結果，不是預先寫好的展示答案；為避免公開電腦使用者名稱，未上傳含本機路徑的 CMD 原始截圖。


測試輸入


您好，我購買的耳機一直沒有收到，請幫我查詢訂單進度。


模型實際回傳的 JSON


{
  "category": "退款退貨",
  "priority": "高",
  "summary": "請聯繫我們的客服，查詢您的訂單進度並提供退款退貨的幫助。",
  "suggested_reply": "您可以在我們的客服網站或是電話我們的客服熱線，與我們的客服人員聯繫。"
}


結果分析：程式成功呼叫 LLM 並取得符合指定四欄位的結構化輸出，但分類結果不理想。客戶只要求查詢未到貨訂單，較合理的類別是「訂單查詢」，不是「退款退貨」。這顯示 JSON 格式正確不代表內容判斷一定正確；實際使用應人工複核，並可透過加入分類定義與範例來改善提示詞。


此為單筆本機實測案例，不代表整體分類正確率。上方互動範例仍是靜態示意，不會在瀏覽器直接呼叫模型。




05｜怎麼執行


先安裝 uv 與 Ollama，並啟動 Ollama：


ollama pull llama3.2
# 視作業系統需要，另開終端執行 ollama serve
git clone https://github.com/justtemp5678-sys/ai-mail-classifier.git
cd ai-mail-classifier
uv run python main.py --text "您好，我的包裹還沒收到，想查詢物流。"


自動測試：
uv run python -m unittest discover -s tests -v


本地模型下載需要網路、記憶體與磁碟空間。輸出可能因模型版本、硬體與輸入而不同。




06｜AI 使用說明與限制


本專案使用 AI 協助規劃、撰寫程式、設計 JSON Schema、測試與作品網頁。分類建議應由人員複核，避免將個資輸入不受控服務。範例展示不冒充模型實跑結果。


程式預設只連至本機 Ollama；.env 被 .gitignore 排除，因此不會把私人設定檔提交到 GitHub。
